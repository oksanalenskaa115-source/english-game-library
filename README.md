# English Game Library

Образовательный сайт с тремя играми по теме Past Simple для детей 10–11 лет. Интерфейс оформлен как приключение в Древнем Египте. Сервер и интернет-регистрация не требуются: профили и результаты хранятся в браузере на устройстве ученика.

## Как запустить сайт

Самый простой вариант в этой папке:

1. Откройте PowerShell в корне проекта.
2. Выполните `./dev.cmd`.
3. Не закрывайте PowerShell, пока работает сайт.
4. Откройте адрес, показанный после слова `Local`, обычно `http://localhost:5173/`.

Если страница уже была открыта, но не обновилась, нажмите `Ctrl + F5`.

## Обычные команды

- `npm run dev` — запустить сайт для разработки.
- `npm test` — один раз выполнить автоматические тесты.
- `npm run test:watch` — повторять тесты после изменений файлов.
- `npm run build` — создать готовую production-версию в папке `dist`.
- `npm run preview` — локально проверить содержимое `dist`.
- `npm run optimize:images` — заново создать облегчённые WebP-копии изображений.

Если команда `npm` блокируется PowerShell, используйте локальный Node:

```powershell
./.runtime/node-v24.18.1-win-x64/npm.cmd run build
```

## Чистая установка

Для проверки проекта на новом компьютере:

```powershell
npm ci
npm test
npm run build
npm run preview
```

После запуска preview откройте адрес из строки `Local`. Проверьте главную страницу и прямые игровые маршруты.

## Изображения

Оригиналы пользователя находятся в `public/images` и не изменяются. Сайт загружает уменьшенные WebP-копии из `public/images/optimized`.

Если оригинальное изображение заменено новой версией с тем же именем, выполните:

```powershell
npm run optimize:images
```

После этого обновите страницу через `Ctrl + F5`.

## Публикация на Netlify

Проект подготовлен для Netlify, потому что этот хостинг поддерживает прямые маршруты React Router через файл `_redirects`.

Вариант через репозиторий:

1. Загрузите проект в Git-репозиторий.
2. В Netlify выберите **Add new site → Import an existing project**.
3. Build command: `npm run build`.
4. Publish directory: `dist`.
5. Запустите публикацию.

Настройки также записаны в `netlify.toml`. После публикации обязательно откройте напрямую адреса `/progress`, `/settings` и любой игровой маршрут. Они должны загружаться без ошибки 404.

Для другого хостинга необходимо настроить правило: любой неизвестный адрес должен возвращать `index.html`. Если сайт размещается не в корне домена, задайте путь перед сборкой, например `$env:VITE_BASE_PATH='/english-games/'`.

## Публикация на GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` автоматически проверяет, собирает и публикует сайт после каждого изменения ветки `main`.

Адрес сайта для этого репозитория:

```text
https://oksanalenskaa115-source.github.io/english-game-library/
```

Если Pages ещё не включён, откройте в GitHub `Settings → Pages` и в поле `Source` выберите `GitHub Actions`. Ход публикации отображается во вкладке `Actions`.

## Работа без интернета

После первой полной загрузки production-сайта браузер сохраняет основную оболочку и игровые изображения. Повторно открыть уже загруженный сайт можно без интернета. Offline-кэш работает только на `localhost` или на сайте с HTTPS.

Профили, темы учителя и результаты хранятся локально. Очистка данных браузера удалит их, поэтому пользовательские темы рекомендуется периодически экспортировать в JSON.

## Проверка перед публикацией

Автоматическая часть:

```powershell
npm test
npm run build
```

Ручная проверка описана в [docs/TEST_CHECKLIST.md](docs/TEST_CHECKLIST.md). Особенно важно проверить телефон, планшет, звук, английскую грамматику и работу `READ STORY` в установленном браузере.

## Важное замечание о React Router

Текущая версия `react-router-dom` закреплена в `package.json`. `npm audit` сообщает о проблеме серверного RSC Mode, но этот проект является обычным клиентским Vite-приложением и не использует RSC, Server Actions или сервер React Router. Не запускайте `npm audit fix --force`: такая команда может установить несовместимую версию.
