## 3. Mummy Memory

- [ ] В начале все карточки закрыты и перемешаны.
- [ ] Правильная пара остаётся открытой.
- [ ] Неправильная пара закрывается примерно через секунду.
- [ ] Во время проверки нельзя открыть третью карточку.
- [ ] За пару начисляется 20 очков, за третью подряд — ещё 10.

- [ ] Бонус времени добавляется только после завершения.

- [ ] На каждом новом вопросе отображаются три сердца.
- [ ] Проверены утверждения, отрицания, вопросы и краткие ответы.

## Журнал дефектов

### TEST-001 — предупреждение npm audit

- **Статус:** проверено на этапе 16; риск не применяется к текущей архитектуре.
- **Что найдено:** `npm audit` сообщает о двух предупреждениях высокой важности в цепочке `react-router-dom` → `react-router`.
- **Условие проблемы:** уязвимость относится к серверному RSC Mode и выполнению Server Actions.
- **Почему сайт продолжает работать:** English Game Library является клиентским Vite-приложением без сервера, RSC и Server Actions.
- **Результат проверки:** безопасной новой версии в npm пока нет; понижение версии возвращает дополнительные известные проблемы. Оставлена актуальная закреплённая версия 7.18.2.
- **Следующее действие:** обновить React Router после выхода исправленной версии, не используя `--force`.

Новых дефектов в протестированной игровой логике не обнаружено.
